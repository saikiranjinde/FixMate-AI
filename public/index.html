03 · GET STARTED

How to download and use

Install once, then run diagnostics whenever your PC starts acting unusual.

01

Download

Press the download button and save the FixMate-AI executable to your Windows PC.

02

Install / Run

Open the downloaded executable. Windows may ask you to confirm the application before launch.

03

Check your PC

Use the Dashboard to see system information, then open Run Diagnosis and start a full scan.

04

Review & fix

Expand diagnostic findings, review the evidence and recommendations, and save the generated report.

AI is optional. You can use the normal FixMate-AI diagnostics without an OpenRouter API key. Add a key only when you want AI explanations.
